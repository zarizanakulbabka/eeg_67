# Класифікація EEG: цифра 6 чи 7
 
Навчальний проєкт з курсу «Основи штучного інтелекту». За 2-секундним записом EEG
(датасет [MindBigData](https://www.kaggle.com/datasets/vijayveersingh/1-2m-brain-signal-data),
гарнітура Emotiv EPOC, 14 каналів) визначаємо, яку цифру бачила людина: 6 чи 7.
 
| Модель | Точність на тесті |
| --- | --- |
| Логістична регресія | 52,4% |
| Random Forest | 53,4% |
| 1D-CNN | 57,6% |
 
Рівень випадкового вгадування — 50,7%.
 
- `eeg67.ipynb` — код і результати (запускається в Google Colab, датасет скачується автоматично)
- звіт у PDF — опис моделей, експерименти і порівняння з літературою
